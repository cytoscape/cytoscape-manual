# move whenever a chapter is edited.

# The categories here, and why they are tolerated rather than fixed:
#
#   myst.xref_missing  By far the bulk. This manual links between chapters
#                      with raw HTML anchors (<a id="foo"> </a>), which MyST
#                      cannot see when it validates a Markdown link target.
#                      The links resolve correctly in the built HTML, so these
#                      are false positives, not broken links -- but clearing
#                      them means revisiting every link in the manual.
#                      Agentic_Integration.md avoids them by writing its
#                      anchor links as raw HTML (<a href="...">), which MyST
#                      passes through without validating. Note that the
#                      Foo.html#anchor Markdown form the README suggests does
#                      NOT avoid the warning -- MyST validates that too.
#
#   toc.not_readable   docs/index.rst lists App_Manager, but that file was
#   toc.not_included   renamed to App_Store.md in 1d276e5 (Dec 2022) and the
#                      toctree was never updated. Sphinx drops the entry, so
#                      the App Store chapter is missing from the published
#                      manual and every later chapter numbers one lower.
#                      Deliberately not fixed here -- it predates this work by
#                      years, and correcting it renumbers 17 chapters, which
#                      belongs in its own change rather than riding along with
#                      a new chapter.
#
#   myst.header        Pre-existing heading-level jumps in older chapters.
#
#   (untyped)          Two conf.py deprecations: get_html_theme_path, and
#                      language = None.
#
# To regenerate after fixing or accepting a warning, run `make build` and then:
#
#   python3 tests/regenerate_warnings_baseline.py
